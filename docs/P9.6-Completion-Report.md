## 二、额外 12 项（计划外发现与修复）

1. **★ validate.ts 玻璃门恒等式假缺陷（真核心缺陷）**：玻璃门走甲购分流不进 `geom.panels`，校验器「Σ门宽+缝=净宽」读到 0 块门板 → 误报「生成器自相矛盾（程序缺陷）」。修复=按 L49-59 既有先例守卫：门板不在切板清单时改验甲购条目（材质/数量），不误报程序缺陷。此缺陷此前不可达（glass 验收走 `generateCabinet` 直连），§二十七 端到端逼出。
2. **真实需求夹具的规范写法**：1200+1000 显式双行超出内高 2066 被诚实拒绝（正确行为）；规范表达=上 1200 显式 + 底 `'fill'`（P1 要求 fill 落最后一行）。未改任何规则，验收里同时钉住「双 fill 仍被拒」。
3. **aigen A10 封闭字段清单补 `doorMaterial`**：契约正当扩容（§二十七），断言意图不变（封闭+类型声明），沿电器格五字段先例。
4. **`cbBody` 提取器修复**：旧 `\},\)` 收口会把 `useCallback` 依赖数组后的邻居函数体吞进断言（20/24 两条假红根因）→ 改 `\},\s*\[`。
5. **源码扫描 vs 注释剥除的假绿教训**：M1 变异锚点「选择此方案」首现在文件头注释（被剥除）→ 变异落进扫描盲区、验收仍绿。教训：变异锚点必须落 JSX 实码。
6. **沙箱 EBUSY 发现**：本环境 node 作为父进程无法 spawn 任何子进程（连 bash 都 EBUSY）→ 变异测试改为「node 补丁器（纯文件读写）+ bash 驱动（跑验收/判红/还原）」两段架构。
7. **ADOPT_LIKE 从死代码变哨兵**：原定义无断言使用；接入断言 35（对比层禁新增 adopt/commit/save 风格 API），M7 变异验证其有效性。
8. **断言 26 消除真空通过**：从「fixture 里碰运气找 unknown」（无 unknown 时恒真）改为**构造**含 `hit:'unknown'` 的 component，映射改坏必红。
9. **变异崩溃 ≠ 断言红**：M3 用不存在的导出名 `deriveFacts` 会让脚本 import 崩溃（exit 1 但无 ✗ 34）——红得没意义；改用真实导出 `deriveSpatial` 让源码扫描断言自己红。
10. **`.tsx` 不可被 Node 验收脚本 import** → 纯逻辑抽 `.ts`（与 `placementIntent.ts` 同一手法），同时逼出「展示投影 / 渲染」边界。
11. **`verify:all` 接线**：两套新脚本插入 manufacturing 与 ui 之间（脚本没接进链路 = 不存在）。
12. **tracked PNG 提交前复位**：`git checkout -- verify/out/`（verify:ui 产出不进 diff）。
