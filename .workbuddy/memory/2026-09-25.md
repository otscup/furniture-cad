## 交付①：复杂柜型能力矩阵（餐边柜 / 岛台 / 洗衣机柜）

用户原话：「如果遇到一些复杂的柜子怎么添加……如果是餐边柜以及岛台橱柜洗衣机柜应该怎么添加」
（master 反馈五件事里的第 1 件，优先级最高）。

**三种柜型的语义落点**（都不是新画法，是往同一份语义模型里加字段）：
- 餐边柜 = 现有分区语义的**模板组合**（sideboard：抽 2 / 开放格 / 对开门层板）。
- 岛台 = `layout.type:'double'` + `backUnits`（前后两排背靠背、共用中板、**没有背板**，
  排深 = 前后对半，前排 +1mm 保证 Σ=depth 严格成立）。
- 洗衣机柜 = `kind:'appliance'` + `appliance:{name, openingWidth/Height/Depth, topDrawers}`。
  洞口是"机器尺寸 + 安装余量"的**合成结果**；机器走甲购件，不进开料清单。

**关键架构决定**：
- **中板即背**：double 柜不产生背板板件；中板 + 后踢脚板替代。背板派生段整体 `if (!DB)` 跳过。
- **两排共用同一套派生函数**：generate 的 `buildRow`、views 的 `drawRowSide`、bodies3d 的 `drawRow`
  —— 前后排只差净宽表/层板深/脸的 Y 区间，绝不写第二份。
- **电器格净高口径**：洞口上方抽屉只拥有 `innerH − openingHeight − 过梁板t`；
  过梁板位置 = 距柜内底 openingHeight；电器格带门 → ERROR（RULE-APPLIANCE-DOOR，编译器与校验器双拦）。
- **矛盾模型不静默画**：type:'double' 无 backUnits / row 带 backUnits → ERROR；派生按 row 兜底保持可画。
- AI 三层防线全部延伸：契约 +5 个电器格字段、语义校验（count→topDrawers 互斥等）与编译器同调一份、
  提示词由词汇表生成自动覆盖。镜像语义：mirrorUnits 前后排一起 reverse。

**验收**：`verify/complex-cabinets-acceptance.ts` 64 项（A 契约 8 / B 三模板零 ERROR /
C 岛台派生+3D+镜像 / D 洗衣机柜过梁板+甲购件分流+洞口硬规则 / E AI 端到端 / F 负样本回归）；
浏览器探针新增 **B38**（AI 一句话建洗衣机柜：洞口三尺寸落地 / 甲购件分流 / 无新 ERROR / undo 一笔收回，
照 B37 教训自带现场存/还原）。`verify:all` EXIT=0，599 项全绿（`verify:cabinets` 已接入全量链）。

## AI「按描述生成」第二轮：L 形橱柜（用户投诉「为什么ai还是无法更加描述生成」）

**投诉**：说「L 新橱柜，长2200，台面宽750，高1000，另外一边长1200」，AI 回
「需要两个柜体配合，但目前我只能创建单个柜体，无法直接生成 L 形结构。请问你希望
把这两个柜体分别放到哪个房间里？1200mm 那一段是柜子的长还是台面长？」

**定位**：该文案全仓库 grep 无匹配 → 是模型自己说出口的，不是代码文案。根因两处：

1. **提示词只枚举动作、从不说动作能组合**。`buildSystemPrompt()` 把 17 个动作一个个
   列出来，模型按"清单里没有 L 形这个动作"推出"系统做不到" —— 它没注意到正上方
   就有 `cabinet.rotate`。→ 新增 `COMPOSITION_GUIDE` 常量并注入提示词。
2. **`cabinet.create` 不带 rotation**（真正的硬伤）。第二条臂只能"先以 0° 建、再
   rotate"，而中间态是没转的那个朝向，位置多半当场撞墙，被严格模式整条拒掉
   （实测报错"嵌进了墙体 1390mm"）。于是转角柜在动作层面**真的拼不出来**。
   → 给 `cabinet.create` 加 `rotation`（enum 0/90/180/270），compile.ts 透传给
   `createCabinet`。旋转角是**落位意图**、不是几何，板件仍由生成器推导。

**规则 5/6 改写**（这两条是元凶）：原来"做不到就别产生动作""有歧义就先问"，被模型
放大成"先反问再说"。新写法把做不做变成可判定序列（直接做 / 组合做 / 真做不到），
反问只留给"一个数字都没给"。另加"永远不要反问用户放到哪个房间"。

**验收**：`verify:aigen` 52→59 项，新增 G 组 16 项。负样本自证两条都做了：
摘掉 rotation → G2~G8 全红；把 COMPOSITION_GUIDE 从提示词删掉 → G11/G12 变红。

**实测几何（厨房 4200×3600，墙厚 120）**：两臂共用角点 (3330,2730)，长边
rotation 180 → AABB x[1130~3330] y[1962~2730]；短边 rotation 270 → x[3330~4098]
y[1530~2730]。贴角不重叠，blockingErrors 0。

**方法论新增**：`Box3D` 的 `sx/sy` 是**局部**尺寸，世界 AABB 必须把局部四角按 rot
转出去再取包络。直接 `cx ± sx/2` 会在转过 90° 的柜子上量出"穿墙 570mm"的假象 ——
我第一次就量错了，差点据此去修一个不存在的 bug。
