## P8.9 实现（Door Swing / Clearance Semantics，基线 `2aeecb0`）
- **目标**：补 Door 核心事实链 `Door Opening → Door Leaf → 90° 开启包络 → Cabinet Clearance`，回答"柜子没挡门洞，但门打开后会撞它吗"。P8.7 的 600mm 是**人流通道**，P8.9 的扇区是**门扇扫过的面积**——两个概念，各用各的阈值。
- **先审查后新增**：通读 types/spatial/designValidation/geometry/placement/relations/projectFile/CommandBus/PropertiesPanel/AI 契约，确认既无 hinge/swing/门扇/净空概念，`Opening` 只有 id/kind/offset/width/name。**只加两个 authored 字段**（各自可缺省），其余全派生。
- **authored**：`Opening.hinge?: 'start'|'end'`、`Opening.swingDirection?: 'into-room'|'out-of-room'`。**两个独立可缺省字段而非成对对象**——"知道铰链在哪、还没想好往哪开"是真实状态，成对＝系统替用户选了一半（断言 5b 钉死）。绝不存 swingArc/leafPolygon/radius/doorAngle（90° 是规则不是几何）。
- **零三角函数**：`closedDir` = ±墙方向 `u`；`m` = ±墙法线 `nRoom`（**"法线⊥方向"是构造性恒等**）；弧用**向量加法二分**（`normalize(a+b)` = 角平分线），`subdivideArc(from,to,8)`；全程只用 `hypot`。验收 30/31 直接扫源码钉 `Math.sin|cos` 不存在。
- **铰链点**：`along = hinge==='start' ? offset : offset+width`；`jamb = wall.start + u*along`; `hinge = jamb + m*(thickness/2)`。`hinge` 语义 = **墙自身**的起点/终点侧（不是屏幕左右）。
- **室内侧**：复用 P8.7 `wallInteriorSide(loop.poly, wall)` → `side ∈ {1,-1,null}`；`m = into-room ? n*side : -(n*side)`。不假设 start→end 恒代表某房间方向（0/90/180/270° 四面墙各验一遍）。
- **unknown 四因**：`no-swing`(缺 hinge 或 direction) / `open-room`(回路不闭合) / `bad-wall`(零长墙) / `bad-span`(span 非法)。unknown **不画包络、不发 issue、不产 clearance**；绝不"默认向内开"，绝不从柜体位置反推方向。
- **判定与 P8.7 同一把尺子**：`polysOverlapInterior` → overlap；`polyDistance ≤ SPATIAL_TOL.TOUCH(1)` → touch（不报）；否则 clear。函数内不写 epsilon。派生数字：`hitRadius`（离铰链）与 **`intrusion`**（沿开启中轴量"柜体从墙面探出多少 mm"，与旋转无关）——一开始只报 hitRadius，探针发现贴墙柜 hitRadius=0、文案变成"只有 0mm"没信息量 → 改报 intrusion。
